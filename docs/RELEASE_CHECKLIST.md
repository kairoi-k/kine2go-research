# Public Release Checklist

Use this checklist when promoting a research milestone to a public release.

- [ ] `README.md` describes the current frozen result rather than an intermediate experiment state.
- [ ] `RESEARCH_MANIFEST.md` and `docs/RESEARCH_INDEX.md` point to the canonical protocol, evaluator, and result artifacts.
- [ ] Frozen evaluator/protocol versions are explicit and historical versions remain traceable.
- [ ] Scientific claims are bounded by completed evidence; planned work is labeled as planned.
- [ ] Hosted static checks pass; research-critical local/integration validation is recorded where applicable.
- [ ] No absolute host paths, credentials, private checkpoints, or accidental OS metadata are newly introduced.
- [ ] Upstream attribution, license, and citation metadata are present.
- [ ] The release/tag points to a reviewed commit rather than a moving experiment branch.
